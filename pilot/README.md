# 串接精靈本機試辦

試辦來源是虛擬教具借用平台。借用核准時，來源後端會透過接線站的發送 API，通知開發者選定的測試收件者。瀏覽器只會顯示連接與發送狀態。

## 啟動

從專案根目錄執行下方指令。已安裝依賴時可直接執行第二行。

~~~powershell
npm ci
node pilot/preview.mjs
~~~

開啟 [串接精靈預覽](http://127.0.0.1:39261/independent-api/source-setup/preview)，或從 [虛擬教具借用平台](http://localhost:39262/equipment) 的「回接線站」進入。兩個服務分別監聽本機連接埠 39261 與 39262，以 Ctrl+C 結束。

## 體驗

1. 選擇教具借用來源，在接線站挑一位收件者，按「允許連接」。
2. 按「前往原平台新增借用申請」，選擇教具並送出借用單。
3. 在「借用審核」按「核准借用」，查看模擬 LINE 收件匣。回接線站可查三段發送狀態。
4. 在精靈按「斷開連接」，會撤銷該試辦事件的憑證。重新連接可更換收件者。

未連接時，虛擬平台也可以核准借用單，這筆核准會標示「核准時尚未連接接線站」。同一次授權可核准多筆借用單並觸發通知。

試辦使用記憶體內資料庫、獨立的來源後端與模擬 LINE。重啟後會重新建立測試帳號與空白的借用工作區。現有正式網站要支援其他來源，需先接入該來源的授權和實際事件。
