# 串接精靈本機試辦

試辦來源是教具借用平台。借用核准時，來源後端會透過接線站的發送 API，通知開發者選定的測試收件者。瀏覽器只會顯示連接與發送狀態。

## 啟動

從專案根目錄執行下方指令。已安裝依賴時可直接執行第二行。

~~~powershell
npm ci
node pilot/preview.mjs
~~~

開啟 [串接精靈預覽](http://127.0.0.1:39261/independent-api/source-setup/preview)。試辦接線站和教具借用平台會分別監聽本機連接埠 39261 與 39262，以 Ctrl+C 結束。

## 體驗

1. 選擇教具借用來源，在接線站挑一位收件者，按「允許連接」。
2. 前往原平台核准測試單，在模擬 LINE 收件匣確認內容。
3. 返回接線站查看三段發送狀態。建立另一張測試單可驗證同一次授權。
4. 在精靈按「斷開連接」，會撤銷該試辦事件的憑證。重新連接可更換收件者。

試辦使用記憶體內資料庫、獨立的來源後端與模擬 LINE。重啟後會重新建立測試帳號、空白連接與借用單。現有正式網站要支援其他來源，需先接入該來源的授權和實際事件。

~~~powershell
node --test pilot/source-setup.test.mjs
~~~
