# Webhook 本機試辦

這個試辦會啟動接線站和虛擬教具借用平台，並預設一條「借用核准」的事件 Webhook。發送資料和模擬 LINE 收件匣都在本機記憶體中，重啟後會重建。

## 啟動

~~~powershell
npm ci
node pilot/preview.mjs
~~~

1. 開啟 [本機接線站](http://127.0.0.1:39261)，使用終端機顯示的測試帳密登入。
2. 進入「教具借用平台」→「事件串接」→「借用核准」的「Webhook 設定」查看該事件網址。
3. 在 [本機教具借用平台](http://localhost:39262/equipment) 送出借用單，並在「借用審核」核准。
4. 除了模擬 LINE 收件匣，也可在接線站的「發送與紀錄」確認處理結果。

以 Ctrl+C 關閉兩個服務。
