Webhook 串接指南

由數位平台的事件觸發 LINE 通知，收件者在接線站設定。

建立事件 Webhook

  1. 在「我的數位平台」選擇平台，開啟「事件串接」。
  2. 點選頁首「＋ 新增事件」，填寫觸發事件名稱，例如「借用核准」。
  3. 按「建立事件」，在新卡片勾選一位或多位收件者，再按「儲存收件者」。
  4. 在事件卡片按「複製 Webhook 網址」，貼到數位平台對應事件的 Webhook 欄位，發送方式選 POST。若平台詢問驗證方式，選「無」。

日後可回到同一張卡片再次複製網址。完整網址具備發送權限，請保存在數位平台的設定。若要停用舊網址，可在卡片右上角的「⋯」管理選單換發或撤銷。

由數位平台發送

將數位平台的發送方式設為 POST。只填網址時，接線站會用事件名稱產生通知文字，例如「借用核准」已觸發，請至數位平台查看。

自訂訊息與避免重複發送（選用）

數位平台若能發送 JSON，可使用 message 自訂通知文字。填入 eventId 作為每筆事件的固定編號，重試時使用相同編號和訊息。

{
  "eventId": "loan-approved-1042",
  "message": "有一筆教具借用已核准，請登入平台查看。"
}

省略事件編號時，每次呼叫都會被視為一筆新通知。

確認通知

在接線站的事件卡按「發送測試」，可先確認 Bot 和收件者。要驗證完整串接，請在數位平台觸發一次實際事件，再到「發送與紀錄」確認 LINE 的受理狀態。

HTTP 202 代表通知已排入發送流程。請在接線站的「發送與紀錄」查看 LINE 受理狀態。
