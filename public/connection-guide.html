LLineBOT 接線站 回接線站

串接精靈指南

讓原平台的後端建立配對，並在指定事件完成時發送 LINE 通知。

建立配對

在原平台後端隨機產生 32 位元組，轉成 Base64URL 字串作為 verifier。對字串做 SHA-256，再將結果轉成 Base64URL 作為 challenge。

POST /api/v1/source-pairings

{
  "sourceName": "教具借用平台",
  "eventName": "借用核准",
  "challenge": "<Base64URL 的 SHA-256 結果>"
}

使用 Content-Type: application/json。HTTP 201 回傳 pairingCode、deviceToken、有效秒數 expiresIn 和輪詢間隔 pollInterval。在來源平台畫面顯示 pairingCode，把 deviceToken 和 verifier 留在後端，供下一步使用。

授權並領取金鑰

開發者登入接線站後，進入要串接的數位平台，在「事件串接」按「開始串接」。貼上配對碼、核對來源與事件、選收件者，再按「允許連接」。

POST /api/v1/source-pairings/claim

{
  "deviceToken": "<建立配對回傳的值>",
  "verifier": "<原平台後端保存的值>"
}

來源後端至少每 5 秒查詢一次。HTTP 202 表示等候授權。HTTP 429 時稍後再查詢。HTTP 200 回傳 integrationId、apiKey 和 endpoint，請把金鑰存到原平台的後端機密設定。HTTP 410 表示應重新建立配對。

由事件觸發通知

在原平台的業務事件成功完成後，由後端呼叫 POST /api/v1/send。

Authorization: Bearer <從後端機密設定讀取 apiKey>
Content-Type: application/json
Idempotency-Key: loan-approved-<借用單識別碼>

{"message":"有一筆教具借用已核准，請登入平台查看。"}

同一筆事件重試時沿用相同的 Idempotency-Key 和訊息。接線站回傳 messageId，可用同一把金鑰呼叫 GET /api/v1/messages/{messageId} 查詢。開發者也可在接線站查看發送紀錄，並請收件者確認是否收到。
